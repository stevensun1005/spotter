# 训练搭子 iPhone 原生 App

**Spotter** scheme 构建 SwiftUI 版 iPhone App，Bundle ID 为 `app.spotter.health`，支持 iOS 16 及以上。App 与 [Cloudflare 网页](https://spotter-free.couple-ledger-service.workers.dev) 通过 HTTPS 访问同一个账号和 D1 数据库。构建 10 是之前的网页壳版本，构建 11 起主界面由 SwiftUI 实现，构建 12 使用 Cloudflare 移动网页的配色、布局及项目资产。

## 使用与数据

- 登录后点悬浮底栏进入「今日」「训练」「统计」和「好友」。iOS 26 及以上使用液态玻璃，较早系统使用毛玻璃材质。「训练」和「统计」之间的绿色播放按钮打开「开练」。有训练进行时，点中间按钮或底栏上方的计时条均可返回。点页面右下方悬浮的星星可打开 AI 教练，关闭后回到原页面或弹窗。相机、照片、分享及账号授权使用 iOS 系统界面。
- Apple 登录通过 AuthenticationServices 验证，Google 使用系统授权窗口。访问码继续支持已有账号。到「设置 → 账号」可把另一个登录方式绑定到同一账号。会话保存在本设备 Keychain。
- 在「开练」面板点「选择模板开练」方形按钮，可从个人模板立即开始一场临时训练。打开计划或自由训练后可以逐组记重量、次数和时长。计时按时间戳计算，可以跨前后台和锁屏。打卡重试沿用训练 ID，账号切换后分别读取各自的草稿。
- 在按秒记录的组点「开始计时」，按该组秒数倒数。点完成才会记入训练，提前完成记录实际已用秒数。点叉可以取消。切到后台或最小化时继续，暂停训练时一起暂停。
- 在「设置 → 训练偏好 → 训练界面」选择「经典列表」或「专注训练」。默认使用经典列表。专注训练突出当前动作和组次，提供大号数据卡、动作和组次切换、下一组预览，以及可增减 15 秒的休息圆环。两种界面使用同一份训练草稿。
- 统计使用 Swift Charts。「打卡历史」按月查看自己的训练和搭子已共享的打卡。点记录进详情，点日期查看当天的训练，自己的同日训练可以排序。今日页和训练页的「查看记录」也打开同一份训练详情。
- 自己的训练可编辑、另存为模板或生成图片分享卡。分享卡可切换样式、合并当天训练和隐藏明细。附带心率默认关闭。图片可以保存到照片或通过系统分享菜单发送。历史训练详情也可以按实际起止时间同步 Apple 健康心率。
- 在「今日」顶部看所选日期所在的周一至周日。深绿色外环显示训练进度，浅蓝色内环显示饮食热量。点任一天或用箭头逐日切换，跨过周末时整条切到相邻一周。首页的饮食、训练和打卡一起更新。向下浏览时，顶部日期条逐步缩成可点选的七天双环栏，下方带虚化渐变。滚回顶部恢复完整日期栏。
- 每次启动默认展开首页饮食汇总，显示热量环、剩余热量、饮水和三项营养进度，点卡片右上角的斜箭头查看所选日期的餐食并使用饮食快捷入口。点叉可以收起。回到首页顶部，点左上角的圆形餐具图标恢复。也可点「开练 → 记录饮食」直接打开所选日期的记餐页。先选食物，再点「完成」选择餐次。
- 体重可以读取并手动同步到账号。步数、活跃能量和系统运动时长可按日期在 App 查看。
- AI 面板支持文本对话、计划问答、草稿预览和保存，以及系统相机和照片选择器。对教练直接说「吃了一个蛋挞作加餐」会按常见份量估算并记入当天，已记入后说「帮我添加进去」会回显已有记录。AI 请求继续走 Cloudflare 的权限和用量限制。
- 设置中的蛋白粉仓库可拍照在设备上读取标签，核对后保存配方并设为训练默认。完成训练时勾选喝过蛋白粉，会用同一笔打卡保存对应的饮食记录。
- 「设置 → 功能模块」开启「教练与学员入口」后，好友页的「找搭子」旁会显示教练入口。可邀请学员、下发计划和接收计划。
- 原生账号设置提供退出和删除账号。Google 需要 Cloudflare 具备 Google OAuth 配置才可发起真实授权。系统 Apple 授权、Apple Watch 来源和相机须用有对应权限的 iPhone 验收。

构建 40 的使用引导进入真实的训练、首页饮食和好友页面。浮层会高亮当前按钮，点按后继续。试填计划和记餐可以直接进入下一步，正式保存仍由用户操作。完成引导后，可打开 AI 教练选择训练目标，也可在「设置 → 关于与更新」重看引导。每日和每月的 AI 消息用量位于「设置 → AI 教练」，达到上限时对话区显示可重试的时间。

已在此设备验证的账号可以离线打开本机训练计划和草稿，打卡先保存到本机，联网后按原记录 ID 补传。器械配置、默认重量单位和休息时长在 App 与 Cloudflare 网页间同步。「设置 → 手表与健康」可选择是否为已上传的训练自动匹配 Apple 健康心率。App 会在前台补读最近七天的训练，并显示最近一次补读结果。好友可查看收到的加油，当前搭子可以提议、接受或取消训练邀约。

构建 24 的训练页可以撤销上一组，组间休息支持以 15 秒调整。缩小训练后，底栏上方显示训练进度和当前倒数，点一下即可返回。「设置 → 计时提醒」可以开启锁屏时的组间休息通知。饮食页可预览并复制往日指定餐次，已复制的食物在重试时跳过。打卡历史可点年月直接跳转，页脚显示打卡天数，并可一键回到本月。

构建 26 在逐组记录中显示上次实际重量与次数，可以沿用后继续编辑。动作进步页汇总近期训练和个人最好成绩。训练草稿与打卡详情分别显示本机保存、等待同步和已同步状态，暂时的连接错误会自动重试。今日页的待调整训练提供单堂或同周期顺延预览，确认后才修改日程。

饮食明细提供「饮食」「饮水」「拍照记录」。点「饮食」先选食物，再点「完成」选早餐、午餐、晚餐或加餐。取消选择会保留食物篮。「拍照记录」直接打开相机，拍完可用 AI 识别。已有组合可从「固定模版」加入食物篮，也可从饮食设置的「管理固定模版」左滑删除。组合保存在这台 iPhone。扫码识别包装份量后，可直接选个数或份数。例如每个 50 g 的蛋挞选 2 个，会按 100 g 计算本次营养。确认的单位会随个人食物保存。实际饮食记录同步到账号。AI 教练的蛋白粉操作回执分别显示仓库、训练默认配方与各日期的饮食结果。

在「饮食详情 → 饮食设置 → 营养目标」可打开「按身体数据计算」。如果缺资料，点估算页的「身体档案」直接去设置。保存所需档案和体重后会自动回到原计算页，手动点返回也会刷新资料并保留所选条件。核对当前身体档案，选择目标方向、日常活动和训练频率后，可查看每日热量与三大营养素。「日常活动」可选择手动输入、Apple 健康、训练日历或自动动态估算。自动模式结合过去 28 个完整日的步数和今天起未来 7 天的训练，给出一周的日均建议。Apple 健康至少需要 14 天有步数。每天打开计算页会刷新，排期变化也会重算。手动与 Apple 健康模式可继续用最近四周的饮食和体重校准。点「填入营养目标」将结果带回可编辑的每日目标，点「保存」后生效。

iOS 26 及以上的训练、统计、动作库和饮食等页面使用系统液态玻璃控件。分段切换和成组按钮共用按压动效，并遵循减少动态效果设置。

构建 28 发送文字后会立即把它移入对话。照片记餐会记住当前这餐的描述和教练的追问，直接在同一对话中补充即可。可读的包装份量和用户明确填写的数量优先。「一碗粥」「一杯牛奶」等有合理依据的常见份量可直接估算并保存，回执显示估算依据，可编辑和撤销。

构建 29 在 App 运行期间保留 AI 教练对话，包含关闭面板和切到后台后返回。彻底退出 App 后，下次启动会开启新对话。已保存的训练和饮食继续出现在各自页面。页面中的筛选、按钮和卡片使用轻量按压反馈。

## 动作库

构建 53 起，右侧器械索引随可用高度均匀排列。也可以从搜索框旁的「筛选动作 → 高级筛选 → 器械」选择中文类别。训练凳、弹力带、绳索和把手等相关器械共用筛选选项。动作详情保留具体主器械和附件。「只显示我的器械」以当前健身房配置为准。

iPhone 包内的 5,685 段原创 3D 示范采用 HEVC 编码，打开动作卡片即可离线播放。目录 ID、封面和时间轴沿用原素材。资源构建与校验见 [产品设计](product-design.md)。

## Apple Watch 训练和小组件

在已配对的 Apple Watch 上安装并打开「训练搭子」。与 iPhone 的 HealthKit 训练镜像需要 iOS 17、watchOS 10 或以上。首次使用心率时，在表上按提示完成 Apple 健康的系统授权。通过 iPhone 的「手表 → 连接」进入时，表上提供「授权并开始」。

- **从表上开始**。在 iPhone 登录并加载今日计划后，打开手表上的「训练搭子」。点选今日计划即可开练，有进行中的训练时可选择继续。iPhone 可连接时使用手机上的同一份训练草稿，两边共用组次顺序。
- **抬腕记组**。专注页显示当前动作、分组、组次和计划节奏。点重量、次数或时长可以用表冠编辑，单侧动作可分别修改左右数值。「完成这组」按当前数值记组。计时动作可以先点「开始计时」。组间休息显示倒数和下一动作，可加减 15 秒、跳过休息或在设置调整震动。点列表图标或左右滑动查看完整动作列表。
- **从表上结束**。打开动作列表，点「结束训练」并确认。与 iPhone 共用草稿时由 iPhone 保存。离线从表上开始的训练会在表上先保存，连接后同步为同一条打卡，并在有样本时附上手表训练摘要。
- **没有带 iPhone**。此前成功同步到手表的当天力量或计时计划支持离线开练。草稿保存在手表，可再次打开 Watch App 继续。尚未完成任何一组或已暂停时，可从动作列表放弃本次训练，计划会保留。由手机发起的训练暂时断开时，表上保留最近进度，重新连接再继续同步操作。

收到实时心率后，Watch App 和 iPhone 的训练类型旁显示 BPM。暂停、断连或超过 30 秒没有新样本时会隐藏旧读数。训练详情的「训练数据」显示当次表上采到的活跃热量、总热量和平均心率。总热量为同一时段的活跃与静息热量之和，缺项显示「—」。手表晚于开练连接时，只覆盖后续测量时段。训练详情的圆形同步按钮也可以从 Apple 健康查找本次心率曲线和相符的手表运动。

编辑支持的表盘，可添加圆形「开练」或矩形「下一练」。也可以把「下一练」加入智能叠放。点按从表上打开训练。圆形入口在有组次时显示完成进度。矩形卡在训练前显示下一堂的日期和名称，在训练中显示进行状态。配对 iPhone 的训练实时活动可在系统支持且已启用时显示腕上专用卡片，含训练计时、组数和休息倒数。表盘进度跟随 WidgetKit 更新。

合成协议测试与 Xcode 编译可核对数据形状和目标配置。首次授权、实时心率、后台倒计时、表盘入口和断线补传需要用配对真机核验。

## iPhone 小组件

登录 App 并加载训练后，长按主屏空白处，选择添加小组件并搜索「训练搭子」。

- 小号「今天开练」可打开当前训练或开始当天安排的训练。未来的计划打开详情，不会提前开始。
- 中号「本周双环」对齐周一到周日。深绿环显示训练完成比例，浅蓝环显示摄入热量占已保存目标的比例。点日卡回到对应日期。
- 「搭子督练」并排显示两个人本周记录。中号支持点某一天打开当天的搭子记录。
- 「今日饮食」显示剩余热量、宏量营养与饮水量。点「拍照记餐」打开相机，点「饮水」打开预填饮水量的记录页。保存了自动估算偏好的用户可点「查看估算」，饮食环按已保存的目标显示。
- 「我的训练周报」显示最近完整周，「年度训练热力图」按最近 365 天的训练分钟显示。

App 在同步训练、完成打卡、饮食变化和回到前台时更新摘要。桌面刷新由系统安排，退出账号时清除摘要。

iOS 16.1 及以上在打开当前训练时启动锁屏实时活动，最小化到首页或切到其他 App 时沿用同一个活动。App 内在训练页顶部或最小化训练条显示计时、组数和可用的手表心率。切到系统主屏幕或其他 App 后，支持灵动岛的机型可显示训练计时和完成组数，展开后可查看下一组、休息倒计时与近期 Apple Watch 心率。点按回到训练。「设置 → 计时提醒 → 锁屏实时训练」可关闭。

实时活动只能在 App 位于前台时开始，灵动岛在离开 App 后出现。iPhone 设置里关闭了训练搭子的「实时活动」时，「锁屏实时训练」下方显示「打开 iPhone 设置」。App 运行期间在锁屏划掉本次训练后，本次训练不再自动显示，设置里出现「重新显示本次训练」。iOS 拒绝请求时显示原因。系统结束的活动，以及 App 未运行时被划掉的活动，会在下次打开 App 时重新开始。连接 Mac 后可在「控制台」按子系统 `app.spotter.health`、类别 `LiveActivity` 查看开关、请求和状态记录。

## 构建

```sh
npm run build
npm test
npm run test:ios-app
npm run test:health-native
npm run ios:source-check
npm run ios:package
```

`ios:package` 在构建前后核对 `origin/main`、健康同步分支和 iPhone 开发分支，并核对 App 连接的 Cloudflare 提交。产物位于 `outputs/`，包括模拟器 ZIP 和构建清单。iPhone 安装使用 Xcode 签名或 TestFlight。

`ios:package` 只检查模拟器 Debug 构建。Xcode 执行 Product → Archive 后，上传前运行 `npm run ios:verify-archive`。它默认检查 `~/Library/Developer/Xcode/Archives` 中最新的 Spotter 归档，也可以传入 `.xcarchive` 路径。检查内容包括 `PlugIns/SpotterWidget.appex` 的标识和版本、扩展是否编入 `SpotterWorkoutLiveActivity`、主程序与扩展是否共用 `SpotterTrainingActivityAttributes`、`NSSupportsLiveActivities`，以及 Watch App。构建号与源码不同时会提示。

TestFlight 使用同一 **Spotter** scheme 的 Release 归档，分发目标是 App Store Connect 的 `app.spotter.health` 应用。主 App 的签名描述文件须支持 HealthKit、Sign in with Apple 和 Associated Domains。随 App 一起归档的 `app.spotter.health.watchkitapp` 需要自己的 HealthKit 签名，`app.spotter.health.watchkitapp.widget` 也需要分发签名。Apple Developer 中的 App Group `group.app.spotter.health` 需分配给 iPhone、Watch 和两个小组件的 App ID。原生 Apple 服务端使用 `APPLE_OAUTH_NATIVE_CLIENT_ID=app.spotter.health`。网页的 Apple Services ID 与原生 App ID 在同一 Apple Developer 配置下管理，详情见 [登录配置](cloudflare-login.md)。

私密 Sites 与独立 Node 自托管服务各有账号和数据。配对码和批量健康同步协议另见 [健康设备同步](health-device-sync.md)。
